# Siemens S7

`s7comm` 是 iView 的 JVM Siemens S7 TCP 驱动，使用 Apache PLC4X 与 PLC 建立 ISO-on-TCP/S7 会话。

## 设备连接参数

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `host` | — | PLC IP 或主机名，必填；兼容 `ip_address` |
| `port` | `102` | S7 TCP 端口 |
| `rack` | `0` | 机架号，0–7 |
| `slot` | `1` | 槽位号，0–31 |
| `connect_type` | `1` | `1` 为 PG/PC、`2` 为 OS、`3` 为其他连接 |
| `timeout` | `5000` | 建连和单次读写超时，单位毫秒 |

驱动启用 TCP keep-alive，并把读超时和 TCP 超时统一映射为设备超时配置。

## 点位地址

点位可以直接使用 PLC4X S7 地址，例如 `%DB1:10:INT`、`%DB1:10.2:BOOL`、`%M0.0:BOOL`；为兼容工程录入习惯，也支持以下简写：

- `DB1.10` 按点位数据类型转换为 `DB1:10:<TYPE>`。
- `DB1.10.2` 转换为 DB 位地址。
- 纯数字地址可通过 `area_type` 和 `db_number` 指定区域与 DB 编号，默认使用 DB1。
- `plc_tag` 可显式覆盖地址转换，适合直接使用完整 PLC4X 标签。

支持 BOOLEAN、INT/UINT 16/32/64、FLOAT32 和 FLOAT64。PLC 返回非 `OK` 响应码时，点位质量为 `BAD_RESPONSE`；超时、配置错误和链路故障分别映射为 `TIMEOUT`、`BAD_CONFIGURATION` 与 `OFFLINE`。传输异常会重新建立连接并重试一次，PLC 明确拒绝的请求不会盲目重试。

正式项目应在目标 S7-200/300/400/1200/1500 PLC 上确认机架槽位、PUT/GET 权限、优化数据块设置、点位边界和连续采集压力。
