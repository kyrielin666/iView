# 真实设备连续运行验收

连续运行验收会按固定间隔调用与正常采集相同的协议驱动、重连和遥测持久化链路，用于现场 RS485、PLC 或 OPC UA 设备的长时间稳定性检查。验收任务和统计结果保存在数据库中，服务意外重启时，未完成任务标记为 `INTERRUPTED`，不会伪装成通过。

- `POST /api/v1/devices/{deviceId}/acceptance-runs`：启动验收，配置持续分钟数、采集间隔、最低成功率和连续失败终止阈值。
- `GET /api/v1/device-acceptance-runs?device_id={id}`：读取验收记录和当前进度。
- `GET /api/v1/device-acceptance-runs/{id}`：读取单次验收报告。
- `DELETE /api/v1/device-acceptance-runs/{id}`：停止进行中的验收。

报告记录采集次数、成功/失败次数、协议重连恢复次数、平均/最大响应耗时、最大连续失败和最后错误。只有运行到计划结束、成功率达到阈值且未触发连续失败阈值时，`passed` 才为 `true`。

这些接口只允许 `ADMIN` 角色调用。启动任务会持续访问真实设备并写入遥测记录，必须在现场确认设备地址、串口独占和采集授权。模拟器与自动化测试只能验证代码逻辑，不能替代真实 PLC/串口设备的验收结果。
